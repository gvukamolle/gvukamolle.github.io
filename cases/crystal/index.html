A personal workflow problem became a public product.

The problem

On a small laptop screen, I had to keep Obsidian, Claude or Codex, and a terminal open at the same time. Window switching broke the workspace, displaced context, and slowed the work. I decided to put agent support directly where the project notes and source material already lived.

I built the first version for myself over two weeks in January 2026. In August, I returned for another week, moved the product to Codex, and prepared the public release. After using it myself, I shared Crystal with five colleagues and three technically experienced friends. Their feedback drove interface cleanup across versions 1.1.7–1.1.9.

Product decision

Crystal is not a generic AI chat or a wrapper for multiple providers. It is an OpenAI Codex workspace inside Obsidian. The current note, selected text, attachments, and linked material become explicit agent context, while the conversation continues between the full workspace and side panel.

The user describes the desired result, and the agent chooses whether to answer from context, research the vault and web, edit material, or combine those steps. A separate mode picker became unnecessary. The visible model choice was reduced to the current GPT-5.6 family, and provider switching was removed: Crystal uses the existing Codex authentication and runtime.

What I removed

I removed a separate task interface, saving every chat as its own Markdown file, the manual mode picker, and an overloaded provider and model selector. Those features increased the number of decisions a user had to make without strengthening the core job: working with a knowledge base through an agent.

Skill and tool integration became a deeper product challenge. Placing a skill beside the plugin was not enough; discovery paths, storage, synchronization, and versioning had to be designed so Codex could reliably find managed instructions without overwriting unrelated skills.

What I owned

I defined the problem, positioning, interaction model, feature scope, permission boundaries, and release standard. AI agents performed implementation, testing, visual quality checks, packaging, and documentation. I decided what belonged in the product and accepted the public release.

Outcome

Crystal is listed in the official Obsidian Community Plugins catalog; the public repository and manifest confirm release 1.1.9. Eight technical users used the early versions. Current feedback is qualitative and does not yet support retention or time-saving claims.

Crystal is desktop-only because it starts the local Codex runtime. It uses the existing Codex authentication and adds no telemetry of its own. Questions do not create files by default, while deletion, bulk moves, and broad vault restructuring require separate confirmation.

Evidence basis and limits

Public release verified

The Obsidian page verifies the catalog listing; the public repository and manifest verify release 1.1.9. The eight-person early-group signal is qualitative, not an adoption metric.
