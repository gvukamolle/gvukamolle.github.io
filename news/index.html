Julia 1 позволяет сортировать тексты без мощной видеокарты

В представленном 26 сентября открытом проекте модель выбирает ответ из заданных вариантов: например, определяет, в какой отдел направить обращение. Веса и код доступны по лицензии Apache 2.0, запуск предусмотрен на обычном процессоре. Julia не ведёт свободный диалог; результаты тестов опубликованы разработчиками, а качество для конкретной задачи нужно проверять отдельно.
